# 快速破坏效果工具

- 本工具用于快速对物体进行分割以及产出破碎动画，含有以下功能：
    - `CellFracture` 参考并派生自[object_fracture_cell](https://projects.blender.org/extensions/object_fracture_cell)
      - 在种子点上构建 3D Voronoi 图，把每个胞体做成凸多面体，再与原物体做**布尔求交**，得到贴合原表面的碎块，用于刚体破坏预切割

当前已实现预切割


## 构建

在本目录运行：

```text
<path_to_blender> -c extension build --source-dir=./source
```

## 安装

直接双击 `install.bat`

```bat
install.bat              :: 自动定位 zip 与 Blender 配置版本并安装
install.bat 5.2          :: 指定 Blender 配置版本目录
install.bat 5.2 -Force   :: 覆盖已安装版本时不询问
install.bat /nopause     :: 结束后不等待按键，可用于自动化测速
```

检测到已有安装时会询问是否覆盖，**默认是覆盖**：直接回车即替换，只有明确输入 `n` 才取消。

## 使用

有两个入口，参数同一套逻辑，可混用：

1. 菜单（弹窗）：3D 视图 → **物体** → **快速效果** → **快速破坏效果**
2. 侧栏面板（常驻）：3D 视图按 **N** → **QuickDestruction** 标签页（中文界面显示为 **快速破坏**）


## CellFracture 

核心算法：拿一批种子点，把物体的包围盒切成一块块 Voronoi 胞体，只保留落在物体内部的部分。

分四步：

1. **取种子点** —— 从物体自身顶点、子物体顶点、粒子位置、或场景注解笔画中采样。**种子点就是这些现成的几何位置，不是随机撒点**；所以默认立方体只有 8 个顶点时，最多只能切出 8 块。
2. **构建有界胞体** —— 对每个种子点，从「物体包围盒六个面」这个初始空间出发，依次用**它与邻近种子点连线的中垂面**去切，只保留靠近自己的一侧。切完剩下的凸多面体就是该种子点的 Voronoi 胞体。为了少算，邻居按由近到远依次试，一旦距离远到切不进来就提前停止。
3. **做成凸体** —— 把胞体顶点喂给凸包运算，得到封闭的凸多面体。
4. **与物体求交** —— 每个胞体与原物体做一次 `INTERSECT` 布尔运算。胞体可能有一部分伸到物体外面，求交之后就只剩下贴合原表面的碎块。

几个由此推出的性质：

- **碎块数 ≈ 种子点数**，不是由某个「块数」参数直接决定。想多切就增加顶点（细分网格）或改用粒子 / 注解作为种子来源。
- **切割面是平面**，因此碎块都是凸的。曲面物体上，断面也是平面而非曲面。
- **种子点分布决定碎块均匀程度**。规则网格的顶点会切出规则整齐的碎块；用「噪波」打散种子点，切面才会变得不规则。
- 求交后**某些胞体可能被判为空**（落在物体外或退化），这类胞体会被丢弃，所以最终碎块数可能少于种子点数。

### 参数参考

种子来源不是随机撒点功能：默认立方体没有粒子时，会使用自身的 8 个顶点。

#### 种子点来源

这一大项决定**碎块的数量与分布**。碎块是围绕种子点生成的，所以种子在哪里、有多少，直接决定切出多少块、均匀还是不规则。想控制「碎成几块」，调的就是这一组。

- **来源**（默认：自身粒子）
  种子点从哪些几何位置采集，可多选：自身顶点、子物体顶点、自身粒子、子物体粒子、场景活动注解层/帧。
  *影响*：这是碎块数量的根本来源。选中的来源一个点都没取到时，会**回退到自身顶点**，不会白跑一趟。
  *示例*：选「自身顶点」切一个细分 2 级的立方体（98 顶点）→ 98 块；只留「自身粒子」而物体没有粒子系统 → 回退成 8 个顶点，切出 8 块。

- **种子点上限**（默认 100，范围 0–5000）
  去重前最多保留多少个采样点，0 表示不限。
  *影响*：只做「截断」，不会补点，也不保证最终块数等于它 —— 截断是**先随机打乱再取前 N 个**，取到的是随机子集。实际块数还会因为去重、胞体被判空而少于它。
  *示例*：UV 球有 1986 个顶点，设为 100 → 约 100 块；设为 0 → 1986 块，但耗时从约 0.4 秒涨到约 39 秒。

- **噪波**（默认 0.5，范围 0–1）
  给每个种子点加随机位移，最大位移 = 包围盒对角线的一半 × 此值，0 表示不扰动。
  *影响*：打散规则点阵。规则网格的顶点会切出整整齐齐的方块，加噪波后切面方向和距离都变得不规则，碎块大小差异明显增大。副作用是部分胞体会退化成空壳而被丢弃，块数会减少。
  *示例*：细分立方体（56 顶点）上，0 → 56 块且最大/最小体积比 1.0；0.8 → 约 46 块，最大/最小比达到 14000 以上。

- **胞体缩放**（默认 1, 1, 1，各轴范围 0–1）
  三个轴向上的正数权重，分别标为 X / Y / Z。
  *影响*：它调制的是**分割平面的方向和距离**，不是缩放物体。三轴相等时不改变分区（走等轴快路径）。它只在种子点分布不规则时才看得出效果。
  *示例*：在规则点阵的立方体上，8 块时完全没有可见变化；在加密网格上，(0.3, 1, 1) 会让沿 X 的切面明显变密。

#### 递归破碎

这一大项决定**是否把碎块再炸一遍**。开启后部分碎块会被继续细分，总块数成倍增长；此时总块数是「首次切割数 × 各轮参与数」的累积结果，不再等于种子点数。

- **递归**（默认 1，范围 0–5000）
  首次切割之后额外做几轮细分，0 表示关闭。
  *影响*：这是与默认值配合最需要留意的一项 —— **默认就开着 1 轮**。1 轮通常就让块数增长数倍。
  *示例*：细分 2 级立方体（98 种子点），只切一次约 98 块；开 1 轮、参与比例 1.0 → 250 块上下。

- **递归种子上限**（默认 8，范围 0–5000）
  每个被递归细分的碎块，在去重前最多采样多少个点，0 表示不限。
  *影响*：**只作用于紧邻的这一层**。它决定每个子碎块被切成几片；设得太小，子碎块只能切成很少几块；设为 0 则用小碎块自身的全部顶点，块数会暴涨。
  *示例*：设为 8 → 每个被递归的碎块大约再分成 6 片；设为 0 → 小碎块顶点全用上，总块数可达数千。

- **碎块停止阈值**（默认 250，范围 0–10000）
  每个源物体的碎块数达到此值后停止继续递归，0 表示不限制。
  *影响*：这是防止递归失控的保险，**不是精确上限**。检查发生在每一层递归开始时，所以最终数量可能**略微超过**所填数值；且首次切割不受它限制。
  *示例*：`种子点上限=40`、`递归=2` 时，设为 0 → 约 2850 块；设为 3 或 7 → 都被压到 48 块。

- **递归参与比例**（默认 1.0，范围 0–1）
  每一轮里有多大比例的碎块参与细分，数量向下取整，0 表示不选、1 表示全选。
  *影响*：控制递归的「稀疏程度」。设为 0.25 时只有约四分之一的碎块被继续炸，其余保持完整，块数增长平缓、碎块大小层次更自然。
  *示例*：250 块的场景，比例 1.0 → 全部参与，块数涨到数百；0.25 → 只有约 60 块被细分。

- **递归对象**（默认：随机）
  参与递归的是**哪些**碎块，下拉选择：随机、小碎块、大碎块、靠近游标、远离游标。
  *影响*：只在参与比例小于 1 时才起作用。大小按世界空间包围盒对角线衡量；游标距离按碎块的**物体原点**计算，而原点默认已被移到几何中心。
  *示例*：想做「大片碎裂 + 少量大块残留」，选「小碎块」并配一个低比例；想只把远处炸碎，选「远离游标」。

- **移除上级碎块**（默认：开）
  递归成功后，删掉被替换掉的那一级碎块。
  *影响*：**最初选中的源物体始终保留**，不受这一项影响，它只清理递归产生的中间碎块。关掉它，中间碎块会和它们的子碎块一起留下，总块数更多，也能看到完整的层级。注意被腾空的组集合会被自动收回，所以关掉它才能看到中间层的集合。
  *示例*：关掉后，一级碎块与其子块并存，便于检查递归选中了哪些碎块。

#### 网格数据

这一大项决定**每个碎块自身的网格长什么样**：断面的着色与锐边、材质与 UV 数据是否继承、碎块之间是否留缝、不连通的部分是否拆开。它不影响碎块的数量与位置。

- **平滑内侧面**（默认：关）
  对新生成的内部断面使用平滑着色，外表面着色仍由源网格继承。
  *影响*：只改着色方式，不改几何。关掉时断面是硬边平面，视觉上更像新敲开的截面。
  *示例*：球体这类曲面物体切出的断面，开启后不会出现明显的硬平面感。

- **锐边**（默认：开）
  把内部断面与外表面交界处的边标记为锐边。
  *影响*：这本身只是标记，要在「应用拆分边」或自定义着色时才体现出来。与「平滑内侧面」相互独立。
  *示例*：一块碎块有 6 条交界边时，开启后这 6 条会被标上锐边标记。

- **应用拆分边**（默认：开）
  在「锐边」开启的前提下，把这些锐边**实际拆开**（复制顶点）。
  *影响*：**注意副作用 —— 会让本来封闭的碎块变成非水密网格**。对显示没影响，但会影响依赖封闭网格的后续处理（例如体积类计算）。
  *示例*：一块碎块有 6 条锐边时，开启后顶点数从 8 涨到 14。

- **匹配数据**（默认：开）
  复制源物体的材质槽，并创建对应的 UV / 颜色层。
  *影响*：布尔插值能把外表面的数据传递到碎块上；**内部断面不会自动展开 UV**。它同时是「材质索引」可调的前提。
  *示例*：源物体有 2 个材质槽，开启后每个碎块也带上这 2 个槽。

- **材质索引**（默认 0，范围 ≥0）
  内部断面使用第几个材质槽，从 0 开始。
  *影响*：只在「匹配数据」开启时可调，因为这时碎块的槽位才与源物体一一对应。填一个不存在的槽位会直接报错。
  *示例*：源物体有「外壳」「内芯」两个槽，填 1 就能让断面用「内芯」。

- **内部顶点组**（默认：关）
  为只属于内部断面的顶点创建名为「内部」的顶点组，与外表面共享的边界顶点**不包含在内**。
  *影响*：给下游（脚本、几何节点、其它插件）提供「哪些点属于断面」的标记，本身不改变几何。
  *示例*：断面顶点被赋予权重 1，可用 `qd_fracture_setup.interior_vgroup_of(obj)` 取到该组。

- **内缩量**（默认 0.001，范围 0–1）
  每个分割平面向内偏移的世界空间长度，单位为 Blender 单位。
  *影响*：让相邻碎块之间留出缝隙，相对两面的间隙约为该值的两倍。**留缝而不是重叠，是为了让刚体模拟更稳定**（重叠的碎块会互相弹开）。它是绝对量，不随物体大小缩放，所以小物体上要调小。
  *示例*：2.0 的立方体上取默认 0.001，材料损失约 0.2%；取 0.05 时碎块明显缩小；取 0.1 时体积和只剩约四分之一；对尺寸 ≲0.005 的物体会直接把胞体缩没。

- **拆分孤岛**（默认：开）
  把每个布尔结果里**互不连通的部分**拆成独立物体。
  *影响*：可能让最终块数**多于**种子点数 —— 一个胞体与物体求交后若得到两块分离的几何，会被拆成两个物体。
  *示例*：切割薄壳类物体时，一个胞体可能同时切到壳的两侧，开启后会得到两块。

#### 物体

这一大项决定**碎块的物体原点放在哪里**。它不改几何，只影响轴心位置，但对后续加刚体有实际影响。

- **重设轴心**（默认：开）
  切割后把每个碎块的原点移到它的几何中心。
  *影响*：**建议保持开启**。实测把两个几何完全重合的立方体从 4 米高落下，原点居中者落地后稳定不动，原点偏移 3 米者一触地就翻倒并横移 3.7 米 —— 原点偏离几何会让碎块在刚体模拟里「重心错位」。关闭后原点会留在种子点位置。
  *示例*：20 块碎块落到地面，开启时约 10 块翻倒，关闭时约 17 块翻倒。

#### 集合

这一大项决定**碎块叫什么名字、放进哪个集合**，也就是大纲里的组织方式。它不影响几何结果。

- **集合**（默认 `cell_collection`）
  输出集合名。留空使用当前集合；否则复用当前视图层中可编辑且可见的集合，或新建一个。
  *影响*：**这个集合始终容纳本次操作的全部碎块** —— 直接容纳，或经由其中的分组集合容纳。
  *示例*：填 `wall_parts` 会新建该集合；留空则碎块直接进入大纲里当前高亮的集合。

- **碎块前缀**（默认 `cell`）
  碎块名的前缀，只用于碎块名，不会出现在集合名里。
  *影响*：方便按名字分辨来源或批次。
  *示例*：填 `碎块` 得到 `碎块_001`。

- **碎块分组**（默认：开）
  开启时按切割层级建立分组集合，关闭时全部碎块平铺在输出集合。
  *影响*：只在开启递归时看得出差别 —— 没有递归时两种情况结果相同（都是平铺）

#### 调试

这一大项是**诊断与性能**相关的开关，正常出效果时都可以不管。

- **实时显示进度**（默认：开）
  切割过程中刷新视口。
  *影响*：能直观看到进度，但会拖慢大规模切割；后台模式（`--background`）下无效。
  *示例*：切 2000 块时关掉它可以明显缩短总耗时。

- **显示种子点**（默认：关）
  生成一个名为 `DebugPoints` 的网格，把实际采样到的种子点显示出来。
  *影响*：用于确认「种子到底取在哪」，不计为碎块。它挂在碎块所在的集合里。
  *示例*：选了「自身粒子」却没切出预期的块数时打开它，就能看出粒子点是否被取到。

- **保留布尔修改器**（默认：关）
  不在胞体上应用布尔修改器，而是原样保留。
  *影响*：此模式**跳过递归、孤岛拆分和内部收尾**，因此碎块保持未求交的凸胞体形状，不是贴合表面的真实碎块。它用于排查布尔问题，不是正常产出模式。
  *示例*：细分 1 级的立方体（8 种子点）开启后，8 个碎块上各留 1 个 `Boolean` 修改器；平时是 0 个。

- **序号位数**（默认 3，范围 0–8）
  碎块序号补零到几位。
  *影响*：只影响名字格式，不影响其它任何行为。补零是为了让大纲按名排序时顺序正确。
  *示例*：1 → `cell_1`；3 → `cell_001`；5 → `cell_00001`。

#### 物理

这一大项**当前完全不生效**：没有任何代码读取它。本工具不创建刚体，因此没有质量可分配。字段保留只是为了旧预设仍能载入。

- **质量模式**（默认：按体积比例）
  预留选项，当前禁用。原设计里「按体积比例」是把总质量按碎块包围盒体积分摊，「统一质量」是给每块指定同一个质量。
  *影响*：无。切割流程从不读取它。
  *示例*：改成任何值都不影响输出。

- **质量**（默认 1 kg，范围 0.001–1000）
  预留选项，当前禁用。原设计里它是质量分配的输入。
  *影响*：无。实测把质量从 1 改到 500，输出完全一致，碎块上也读不到任何质量数据。
  *示例*：无。
