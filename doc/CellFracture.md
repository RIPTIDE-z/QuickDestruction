# CellFracture

`CellFracture` 参考并派生自 [object_fracture_cell](https://projects.blender.org/extensions/object_fracture_cell)。

## 核心算法

拿一批种子点，把物体的包围盒切成一块块 Voronoi 胞体，只保留落在物体内部的部分。

分四步：

1. **取种子点** —— 从物体自身顶点、直接子物体顶点、粒子位置或场景活动注解层/帧中采样。种子来自这些现成位置，噪波只扰动位置，不增加种子。无其他来源时，默认立方体回退到自身的 8 个顶点。
2. **构建有界胞体** —— 从外扩后的物体包围盒六个面出发，用种子与邻居之间的分割平面逐步裁切。等轴权重时是普通 Voronoi 分区；非等轴权重会改变平面方向和距离。只有等轴路径使用按距离提前停止的优化。
3. **做成凸体** —— 把胞体顶点喂给凸包运算，得到封闭的凸多面体。
4. **与物体求交** —— 每个胞体与源物体的求值几何做一次 `INTERSECT` 布尔运算，去掉胞体伸出源物体的部分。使用 Exact 求解器；开放或非流形输入自动启用孔洞容错。开放表面仍有体内外判定歧义，适用范围见下节。

几个由此推出的性质：

- 首次切割中，每个有效种子最多构建一个胞体；空布尔结果会被丢弃。孤岛拆分和递归可增加最终对象数量，因此种子数不是最终碎块数上限。默认开启一轮递归。
- 新构建的胞体是凸多面体，分割面是平面；与非凸源物体求交后的碎块可能非凸。孤岛拆分只分离不连通部分，不保证凸性。
- **种子点分布决定碎块均匀程度**。规则网格的顶点会切出规则整齐的碎块；用「噪波」打散种子点，切面才会变得不规则。
- 求交后**某些胞体可能被判为空**（落在物体外或退化），这类胞体会被丢弃，所以最终碎块数可能少于种子点数。

## 输入网格与布尔容错

封闭非凸网格可以直接参与切割，不要求源物体是凸体。对默认猴头这类眼部有开口的网格，工具会自动启用 Exact 的 Hole Tolerant（孔洞容错），改善布尔求交错误保留胞体外部面的情况。

判断依据是**修改器之后的实际求值网格**，不是原始网格是否看起来封闭。每个源物体和每轮递归父块都会独立判断；普通封闭流形网格保持标准 Exact 路径。工具不修改源物体去补洞、重算法线或重网格，也不会自动启用自相交求解。

若某次布尔结果包含非有限坐标，或在考虑尺寸和浮点误差后仍明显超出当前源物体的世界包围盒，会报错并回滚本次切割，避免错误碎块继续递归。保留布尔修改器的调试模式检查的是**求值结果**，不会因基础凸胞体本身伸出源物体而误报。

孔洞容错不是实体修复，包围盒检查也不是严格的凹形体内包含验证。开放表面、自相交或其他无效几何仍可能产生不符合预期的局部结果。如果后续碰撞、体积计算或绑定要求封闭实体，应先明确并准备合适的源几何；本工具不保证容错切割后必定水密，实际拆边选项也会影响拓扑。

## 参数参考

种子来源不是随机撒点功能：默认立方体没有粒子时，会使用自身的 8 个顶点。

以下示例说明参数含义，不保证固定块数或耗时。需要比较单次切割时，显式设置递归为 0、噪波为 0，并保持随机种子一致；默认噪波与递归会使结果不同。同一 Blender 版本、相同源物体及其名称、几何/修改器/点源状态、帧、相关游标位置和参数下，相同随机种子可复现几何结果。多源按物体名排序后共用本次运行的随机流；增加、删除或重命名源物体可能改变随机流分配，不保证跨 Blender 版本逐浮点一致。测试方法与可复现用例见 [测试说明](../tests/README.md)。

### 种子点来源

这一大项决定**碎块的数量与分布**。碎块是围绕种子点生成的，所以种子在哪里、有多少，直接决定切出多少块、均匀还是不规则。想控制「碎成几块」，调的就是这一组。

- **来源**（默认：自身粒子）
  种子点从哪些几何位置采集，可多选：自身顶点、子物体顶点、自身粒子、子物体粒子、场景活动注解层/帧。
  *影响*：这是碎块数量的根本来源。选中的来源一个点都没取到时，会**回退到自身顶点**，不会白跑一趟。
  *示例*：源网格有 98 个不同顶点时，可提供 98 个自身顶点种子；只有“自身粒子”但没有粒子系统时，会回退到源网格顶点。子物体仅指直接子物体，子物体粒子不指粒子系统的子粒子实例。

- **种子点上限**（默认 100，范围 0–5000）
  去重前最多保留多少个采样点，0 表示不限。
  *影响*：只做「截断」，不会补点，也不保证最终块数等于它 —— 截断是**先随机打乱再取前 N 个**，取到的是随机子集。实际块数还会因为去重、胞体被判空而少于它。
  *示例*：源网格有 1986 个采样点时，设为 100 会随机保留 100 个点再去重；设为 0 则保留全部。较多种子会增加求胞体和布尔运算的成本。

- **噪波**（默认 0.5，范围 0–1）
  给每个种子点加随机位移，最大位移 = 包围盒对角线的一半 × 此值，0 表示不扰动。
  *影响*：打散规则点阵。规则网格的顶点会切出整整齐齐的方块，加噪波后切面方向和距离都变得不规则，碎块大小差异明显增大。副作用是部分胞体会退化成空壳而被丢弃，块数会减少。
  *示例*：比较 0 与 0.8 可观察规则点阵被打散后的形状差异；没有固定的碎块数或最大/最小体积比保证。

- **随机种子**（默认 0，范围 0–2147483647）
  统一控制种子点随机截断、噪波方向与幅度、随机递归选择，以及凸包前的数值抖动。
  *影响*：相同输入与种子重复执行会复现切割；修改种子可尝试另一种破碎图案。0 是固定种子，不表示每次随机。噪波为 0 时仍有数值抖动，但它也由此种子控制。切割不改变 Python 或 mathutils 的全局随机状态。
  *兼容*：随机种子随场景参数和新 JSON 预设保存；旧预设缺少此字段时，沿用当前界面的种子（新场景默认 0）。旧脚本直接调用管线而未传种子时使用 0。旧版没有记录完整随机状态的历史切割无法据此还原；已存在结果的重名后缀也不属于几何复现保证。
  *验证*：[可复现性回归测试](../tests/test_reproducibility.py) 可在项目根目录运行：`blender --background --factory-startup --python-exit-code 1 --python tests/test_reproducibility.py`。

- **胞体缩放**（默认 1, 1, 1，各轴范围 0.001–1）
  三个轴向上的正数权重，分别标为 X / Y / Z。
  *影响*：它调制分割平面的方向和距离，不缩放物体。三轴相等时不改变分区；非等轴权重的具体效果取决于种子位置和分割法线。小于 0.001 的旧预设值会被拒绝并报告字段名，不会静默改成其他数值。
  *示例*：(0.3, 1, 1) 会改变部分分割平面；某些轴对齐对称点集可能看不出变化，不能解释为按 X 方向直接压缩胞体。

### 递归破碎

这一大项决定是否继续细分已有碎块。每轮保留数等于“当前数 + 成功生成的子块数 − 实际删除的父块数”，并受参与比例和中途停止阈值影响。保留布尔修改器时，整段递归被跳过，相关参数置灰。

- **递归**（默认 1，范围 0–5000）
  首次切割之后额外做几轮细分，0 表示关闭。
  *影响*：这是与默认值配合最需要留意的一项 —— **默认就开着 1 轮**。1 轮通常就让块数增长数倍。
  *示例*：设为 0 只执行首次切割；设为 1 且比例为 1 时，会继续尝试细分当前碎块，直至这一轮完成或停止阈值触发。

- **递归种子上限**（默认 8，范围 0–5000）
  每个被递归细分的碎块，在去重前最多采样多少个点，0 表示不限。
  *影响*：作用于所有递归轮次中的每个被细分碎块。种子仍按来源设置采集；没有所选来源时，回退到该碎块自身顶点。
  *示例*：设为 8 时，每次细分在去重前最多保留 8 个种子；设为 0 保留该次采集的全部点，不保证固定子块数量。**注意上限只在该值小于被细分碎块自身的顶点数时才起作用** —— 默认立方体的一级碎块只有 8 个顶点，所以设为 8 与设为 100 的结果都是每个碎块再分成 8 块，再往上不会有变化。

- **碎块停止阈值**（默认 250，范围 0–10000）
  每个源物体的碎块数达到此值后停止继续递归，0 表示不限制。
  *影响*：它是停止阈值，不是精确上限。每轮开始和每个父碎块细分前都会检查；一次细分或孤岛拆分可能使结果超过阈值，超过量没有固定保证。首次切割不受此项限制。
  *示例*：首次已有 8 块且阈值为 8 时，不再继续递归；阈值为 9 时，可以执行下一次细分，其结果可能超过 9 块。

- **递归参与比例**（默认 1.0，范围 0–1）
  每一轮里有多大比例的碎块参与细分，数量向下取整，0 表示不选、1 表示全选。
  *影响*：控制递归的「稀疏程度」。设为 0.25 时只有约四分之一的碎块被继续炸，其余保持完整，块数增长平缓、碎块大小层次更自然。
  *示例*：当前 250 块且停止阈值尚未触发时，比例 0.25 先选出 62 块候选；实际处理数量还受后续阈值检查影响。3 块乘以 0.25 向下取整为 0，不细分任何碎块。

- **递归对象**（默认：随机）
  参与递归的是**哪些**碎块，下拉选择：随机、小碎块、大碎块、靠近游标、远离游标。
  *影响*：只在参与比例大于 0 且小于 1 时起作用，其他情况置灰。大小按世界空间包围盒对角线衡量，不是实际体积；游标距离按碎块的物体原点计算，而原点默认已被移到几何中心。
  *示例*：想做「大片碎裂 + 少量大块残留」，选「小碎块」并配一个低比例；想只把远处炸碎，选「远离游标」。

- **移除上级碎块**（默认：开）
  递归成功后，删掉被替换掉的那一级碎块。
  *影响*：最初选中的源物体始终保留。关闭时，生成的父块与子块会重叠保留，父块还可能在后续轮次再次参与细分；层号表示生成轮次，不保证严格树形深度。被腾空的组集合会自动清理。
  *示例*：关掉后，一级碎块与其子块并存，便于检查递归选中了哪些碎块。

### 网格数据

这一大项控制断面着色、数据层、间隙和拓扑收尾。内缩量会改变几何边界，孤岛拆分会影响对象数量，实际拆边会改变拓扑；不能把整组理解为只影响显示。

- **平滑内侧面**（默认：关）
  对新生成的内部断面使用平滑着色，外表面着色仍由源网格继承。
  *影响*：只改着色方式，不改几何。关掉时断面是硬边平面，视觉上更像新敲开的截面。
  *示例*：开启后新断面使用平滑着色，但几何断面仍然是平面。

- **锐边**（默认：开）
  把内部断面与外表面交界处的边标记为锐边。
  *影响*：标记可供 Blender 的锐边着色和后续拆边使用，本身不拆开顶点。与“平滑内侧面”相互独立，关闭后仍可重新开启。
  *示例*：一块碎块有 6 条交界边时，开启后这 6 条会被标上锐边标记。

- **应用拆分边**（默认：开）
  在“锐边”开启的前提下，把全部已标记锐边实际拆开（复制顶点），也可能包含继承自源网格的锐边。
  *影响*：可能让原本封闭的碎块变为非水密网格，并影响依赖封闭网格的后续处理。需要体积或其他封闭几何处理时，可关闭此项，仅保留锐边标记。
  *示例*：锐边两侧不再共享顶点；增加多少顶点取决于实际拓扑。

- **匹配数据**（默认：开）
  复制源物体的材质槽，并创建对应的 UV / 颜色层。
  *影响*：布尔插值能把外表面的数据传递到碎块上；**内部断面不会自动展开 UV**。它同时是「材质索引」可调的前提。
  *示例*：源物体有 2 个材质槽，开启后每个碎块也带上这 2 个槽。

- **材质索引**（默认 0，范围 ≥0）
  内部断面使用第几个材质槽，从 0 开始。
  *影响*：只在“匹配数据”开启时可调。启用匹配时，大于 0 且越界的索引会报错；索引 0 在没有材质槽时也允许，但不会凭空创建材质。
  *示例*：源物体有「外壳」「内芯」两个槽，填 1 就能让断面用「内芯」。

- **内部顶点组**（默认：关）
  为只属于内部断面的顶点创建名为「内部」的顶点组，与外表面共享的边界顶点**不包含在内**。
  *影响*：给下游提供内部顶点标记，本身不改变几何。判定在实际拆边前进行，拆边产生的边界顶点副本不会重新分类。
  *示例*：断面顶点被赋予权重 1，可用 `qd_fracture_setup.interior_vgroup_of(obj)` 取到该组。

- **内缩量**（默认 0.001，范围 0–1）
  每个分割平面向内偏移的世界空间长度，单位为 Blender 单位。
  *影响*：相邻分割面间隙约为该值两倍。它是绝对量，不随物体大小缩放，小物体上应相应调小；过大可能使胞体消失。它不能代替后续刚体碰撞参数的设置。
  *示例*：0.001 对应相邻平面约 0.002 Blender 单位的间隙，实际体积损失取决于形状和种子分布。

- **拆分孤岛**（默认：开）
  把每个布尔结果里**互不连通的部分**拆成独立物体。
  *影响*：可能让最终块数**多于**种子点数 —— 一个胞体与物体求交后若得到两块分离的几何，会被拆成两个物体。
  *示例*：切割薄壳类物体时，一个胞体可能同时切到壳的两侧，开启后会得到两块。

### 物体

这一大项决定**碎块的物体原点放在哪里**。它不改几何，只影响轴心位置，但对后续加刚体有实际影响。

- **重设轴心**（默认：开）
  切割后把每个碎块的原点移到它的几何中心。
  *影响*：使用 Blender 的 `ORIGIN_GEOMETRY / MEDIAN` 放置原点，不等于按体积计算的精确质量中心。原点可能影响后续刚体行为，但本工具不执行物理模拟。关闭后原点留在种子点位置。
  *示例*：重设前后几何位置不变，变的是物体原点及顶点的局部坐标。

### 集合

这一大项决定**碎块叫什么名字、放进哪个集合**，也就是大纲里的组织方式。它不影响几何结果。

- **集合**（默认 `cell_collection`）
  输出集合名。留空使用当前集合；否则按名称查找已有集合，要求其可编辑且在当前视图层可见。不存在时新建；同名集合只在其他场景或不可见时会报错，不会另建同名集合。
  *影响*：**这个集合始终容纳本次操作的全部碎块** —— 直接容纳，或经由其中的分组集合容纳。
  *示例*：不存在 `wall_parts` 时会新建它；留空则使用当前上下文集合。

- **碎块前缀**（默认 `cell`）
  碎块名的前缀，只用于碎块名，不会出现在集合名里。
  *影响*：便于人为区分批次。多源或重复操作使用同一前缀时，Blender 可能添加 `.001` 等重名后缀；显示名不是稳定身份标识。
  *示例*：填 `碎块` 得到 `碎块_001`。

- **碎块分组**（默认：开）
  开启时按切割层级建立分组集合，关闭时全部碎块平铺在输出集合。
  *影响*：首次切割的剩余块始终平铺在输出集合；第 n 轮每个成功细分父块的产物对应 `Ln_Gm` 组集合，碎块名如 `cell_L1G1_001`。关闭分组仍维护逻辑层/组标记。没有递归或保留布尔修改器时此项置灰。

### 调试

这一大项是**诊断与性能**相关的开关，正常出效果时都可以不管。

- **实时显示进度**（默认：开）
  切割过程中刷新视口。
  *影响*：刷新视口便于观察中间结果，但可能拖慢大规模切割；后台模式（`--background`）下无效。进度条仍按源物体更新，不是按每个胞体更新。
  *示例*：切 2000 块时关掉它可以明显缩短总耗时。

- **显示种子点**（默认：关）
  生成一个名为 `DebugPoints` 的网格，把实际采样到的种子点显示出来。
  *影响*：用于确认「种子到底取在哪」，不计为碎块。它挂在碎块所在的集合里。
  *示例*：选了「自身粒子」却没切出预期的块数时打开它，就能看出粒子点是否被取到。

- **保留布尔修改器**（默认：关）
  不在胞体上应用布尔修改器，而是原样保留。
  *影响*：此模式跳过递归、孤岛拆分和内部收尾。基础网格仍是凸胞体，但启用的修改器会在视口和求值几何中显示求交结果；只是没有将结果烘焙回基础网格。相关无效参数会置灰，内缩量和平滑内侧面仍可调。
  *示例*：每个生成胞体保留一个指向源物体的 `Boolean` 修改器；正常模式会把求值结果写入网格并移除该修改器。

- **序号位数**（默认 3，范围 0–8）
  碎块序号补零到几位。
  *影响*：只控制序号的最小显示宽度，数字超过位数不会截断。层号和组号未补零，加上重名后缀等因素，不能保证整个大纲按创建顺序排序。
  *示例*：1 → `cell_1`；3 → `cell_001`；5 → `cell_00001`。

### 物理

这一大项不参与切割或质量计算。本工具不创建或修改刚体；字段仍由序列化和校验读取，保留用于兼容旧预设，界面禁用。

- **质量模式**（默认：按体积比例）
  预留选项，当前禁用。原设计里「按体积比例」是把总质量按碎块包围盒体积分摊，「统一质量」是给每块指定同一个质量。
  *影响*：无。切割流程从不读取它。
  *示例*：改成任何值都不影响输出。

- **质量**（默认 1 kg，范围 0.001–1000）
  预留选项，当前禁用。原设计里它是质量分配的输入。
  *影响*：不会分配质量，也不会改变切割结果。
  *示例*：无。
