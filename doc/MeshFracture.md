# MeshFracture - 网格破碎

流程：采样种子点 → 在包围盒内构造 Voronoi 胞体 → 凸包 → 与源物体做 Exact 布尔求交 → 递归细分 → 断面收尾。

入口是侧栏 **QuickDestruction** 标签页里的 **MeshFracture／网格破碎** 面板：在物体模式下选中网格，点击最上方的 **Generate Fragments／生成碎块**。源物体始终保留，按 **Ctrl+Z** 可以撤销整次生成。

面板布局如下：

- **主面板**：生成按钮，以及来源、种子点上限、噪波、随机种子、切面内缩量；来源按"自身""子物体"各一行顶点与粒子按钮，注解铅笔单独一行；
- **子面板**：递归破碎（含递归轮数）、胞体形状（分割轴权重，默认收起）、断面与碎块；
- **底部按钮**：输出与调试很少调整，画成并排的两个弹出按钮；
- **标题栏**：预设入口在面板标题栏右侧。

下面的参数表按用途分组，与子面板的划分不完全对应。

## 点源与数量

| 参数 | 字段 | 默认 / 范围 | 含义 |
| --- | --- | --- | --- |
| 来源 | `source` | 自身粒子，可多选 | 见下表；选中的来源一个点都没有时，回退到自身顶点 |
| 种子点上限 | `source_limit` | 100 / 0–5000 | 去重前随机截取，0 表示全部保留，不会补点 |
| 噪波 | `source_noise` | 0.5 / 0–1 | 种子沿随机方向位移，最大为包围盒对角线 × 值 / 2 |
| 随机种子 | `random_seed` | 0 / 0–2147483647 | 控制截取、噪波、递归选择与数值抖动，0 也是固定种子 |
| 分割轴权重 | `cell_scale` | (1, 1, 1) / 每轴 0.001–1 | 切割平面的轴向权重，只有三轴之间的比例起作用，某一轴权重越小，碎块沿该轴越长；不缩放物体，三轴相等时等同于普通 Voronoi |

| 来源值 | 读取位置 |
| --- | --- |
| `VERT_OWN` | 源网格的原始顶点 |
| `VERT_CHILD` | 直接子物体的顶点；网格用原始顶点，其他可转换类型用求值几何 |
| `PARTICLE_OWN` | 源物体全部粒子系统中所有粒子的当前位置，包括未出生与已死亡的粒子，不含子粒子 |
| `PARTICLE_CHILD` | 直接子物体的粒子系统 |
| `PENCIL` | 场景活动注解层在当前帧的笔画点，不读取蜡笔物体 |

- 种子数不等于碎块数：去重、退化胞体与空交集会减少块数，递归与孤岛拆分会增加块数。
- 默认立方体没有粒子，因此回退为 8 个顶点种子；把上限调高不会增加种子。

## 递归

| 参数 | 字段 | 默认 / 范围 | 含义 |
| --- | --- | --- | --- |
| 递归 | `recursion` | 1 / 0–5000 | 首次切割之后的额外轮数；首次切割是第 1 层，每轮递归加一层 |
| 递归种子上限 | `recursion_source_limit` | 8 / 0–5000 | 每个父碎块去重前的采样上限，0 表示全部保留；父碎块没有粒子与子物体，除非选中注解铅笔，种子就是它自己的顶点，上限超过顶点数后不再有变化 |
| 碎块停止阈值 | `recursion_clamp` | 250 / 0–10000 | 每个源的碎块数达到阈值后停止细分，0 表示不设阈值；不限制首次切割，单次细分或孤岛拆分可能超出 |
| 递归参与比例 | `recursion_chance` | 1 / 0–1 | 每轮参与的碎块数 = 向下取整(当前碎块数 × 比例) |
| 递归选择方式 | `recursion_chance_select` | `RANDOM` | 比例严格介于 0 与 1 之间时才有效，见下表 |
| 移除上级碎块 | `use_remove_original` | 开 | 细分成功后删除父碎块；关闭时父碎块按层移进 `<源物体>_Parents` 下的 `<源物体>_Parents_L<层>`，带 `_qd_parent` 标记，不再参与之后的递归，也不计入生成结果 |

| 选择值 | 优先选择 |
| --- | --- |
| `RANDOM` | 随机 |
| `SIZE_MIN` / `SIZE_MAX` | 世界包围盒对角线较小 / 较大的碎块 |
| `CURSOR_MIN` / `CURSOR_MAX` | 原点离 3D 游标较近 / 较远的碎块 |

一次生成的碎块总数上限为 10000。超出时报错并撤销本次生成，避免种子数或递归不设上限时长时间卡住。

## 断面与碎块

| 参数 | 字段 | 默认 / 范围 | 含义 |
| --- | --- | --- | --- |
| 平滑内侧面 | `use_smooth_faces` | 关 | 断面平滑着色；外表面沿用源物体的着色 |
| 锐边 | `use_sharp_edges` | 开 | 把断面与外表面的交界边标为锐边 |
| 断面材质索引 | `material_index` | 0 / ≥ 0 | 断面使用的材质槽，从 0 开始；大于 0 且槽位不存在时报错 |
| 内部顶点组 | `use_interior_vgroup` | 关 | 创建 `Interior` 顶点组，只给断面独占的顶点赋权重 1 |
| 切面内缩量 | `margin` | 0.001 / 0–1 | 切割平面向内偏移的绝对长度，相邻碎块间隙约为它的 2 倍；小物体需要相应调小，过大会让胞体消失 |
| 拆分孤岛 | `use_island_split` | 开 | 把不连通的部分拆成独立碎块，拆分后不保证是凸体 |
| 重设原点 | `use_recenter` | 开 | 原点移到顶点平均位置，世界几何不动 |

- 碎块总是复制源物体的材质槽与 UV、颜色层，外表面数据由布尔插值传递，断面 UV 不展开。
- 锐边只做标记，不拆开几何，不会让封闭的碎块变得不水密。
- 焊接容差为源物体包围盒对角线 × 1e-4，所以结果与物体的绝对大小无关。

## 输出

| 参数 | 字段 | 默认 / 范围 | 含义 |
| --- | --- | --- | --- |
| 集合 | `collection_name` | `cell_collection` | 空名使用当前集合；否则按名查找，找不到时新建。集合必须可编辑，并且在当前视图层可见 |
| 碎块前缀 | `shard_prefix` | `cell` | 碎块名的前缀 |
| 序号位数 | `shard_index_padding` | 3 / 0–8 | 名字里每段序号的最小补零位数，位数更多的序号不截断 |
| 碎块分组 | `use_shard_collections` | 开 | 每次切割的碎块放进以被切物体命名的组集合；关闭时全部直接放在输出集合 |

**命名规则**：

- 碎块名由前缀、源物体名与每层一段序号组成，序号段数就是层级：
  - `cell_Cube_003` 是首次切割（第 1 层）的第 3 块；
  - `cell_Cube_003_002` 是从 `cell_Cube_003` 再切出的第 2 块（第 2 层）；去掉最后一段就是父碎块的名字。
- 开启碎块分组时，每次切割的碎块放进以被切物体命名的集合：首次切割的集合叫 `Cube`，从 `cell_Cube_003` 切出的碎块放在集合 `cell_Cube_003` 里。父块被替换后腾空的组集合会被删除。
- 保留上级碎块时，输出集合的结构如下：

  ```
  cell_collection
  ├─ Cube_Parents
  │  ├─ Cube_Parents_L1      cell_Cube_001 …        首次切割后又被细分的碎块
  │  └─ Cube_Parents_L2      cell_Cube_001_002 …    第 2 层又被细分的碎块
  ├─ cell_Cube_001_002       cell_Cube_001_002_001 …
  └─ …
  ```
- 源物体名在名字里最多占 32 字节（UTF-8）：
  - 前 32 字节相同的几个源仍可能撞名；
  - 默认前缀与序号位数下，5 层以内不超过 Blender 4.2 的 63 字节名字上限，更深或前缀更长时名字会被截断。
- 重复切割同一源时，旧碎块仍然保留，新碎块的名字由 Blender 加后缀区分。

名字不是稳定的身份标识。下游脚本应按碎块上的标记筛选：`_qd_source`（完整源名）、`_qd_level`（层级，首次切割为 1）、`_qd_path`（逐层序号，去掉最后一项就是父碎块的路径），保留的上级碎块另带 `_qd_parent`。

## 调试

| 参数 | 字段 | 默认 | 含义 |
| --- | --- | --- | --- |
| 实时显示进度 | `use_debug_redraw` | 关 | 每个胞体刷新一次视口，被切割的物体在切割期间显示为线框；会让切割慢数倍，后台模式下无效 |
| 显示种子点 | `use_debug_points` | 关 | 每次切割（包括递归）生成一个 `DebugPoints` 物体，显示加入噪波后的种子点，不计入碎块 |
| 保留布尔修改器 | `use_debug_bool` | 关 | 在凸胞体上保留布尔修改器，并跳过递归、孤岛拆分与断面收尾 |

## 复现与边界

- **复现**：Blender 版本、源物体的名字、几何与修改器、种子来源、当前帧、游标位置以及参数都相同时，结果可以复现。多个源按名字排序并共享同一个随机流，所以增删或改名源物体会改变后面的结果。
- **预设**：保存在扩展用户目录的 `presets/mesh_fracture/`。
  - 缺少的字段保留界面当前值；
  - 未知字段、其他工具的预设与不支持的格式都会被拒绝；
  - 载入可以用 **Ctrl+Z** 撤销。
- **源网格**：
  - 开启锐边或内部顶点组时，切割期间会临时清除源网格的面隐藏标记，结束后还原；共享同一网格的物体在切割期间也会看到这一变化；
  - 来自链接库的网格无法改写，需要关闭这两项才能切割。
- **布尔**：
  - 按实际的求值网格判断，开放或非流形的输入会启用 Hole Tolerant；
  - 结果出现非有限坐标，或明显超出源包围盒时：越界的情况会先开启自交处理重试一次，仍失败就整次报错并撤销，不会修补源几何。这项检查不保证凹形体的内包含关系，也不保证水密。
- **阶段 API**：脚本调用方式见[架构文档](Architecture.md#阶段-api)。缺少的字段取默认值，未知字段会被拒绝。
