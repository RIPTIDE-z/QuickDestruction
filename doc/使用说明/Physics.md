# Physics - 物理设置

为破碎资产的每块碎块建立刚体，按材料写入质量与碰撞属性，把原点移到质心，记下静止姿态，并记录资产级的**受击前状态**。物理设置本身不推进模拟，碎块何时运动由 [模拟烘焙](Simulation.md) 决定。

## 面板

```text
物理设置                                   [预设]
  Cube: 120 块碎块                          当前资产
  状态      ✓ 输入未变                      未完成 / 已过期 (下一行写原因) / 输入未变
  [面板与已应用的设置不同] [读取已应用的设置]   只在两者不同时出现
  [        应用物理        ]
  [ 移除物理 ][ 设为静止姿态 ]
  ▾ 材料          材料下拉与五个物理量
  ▾ 受击前状态    冻结 | 休眠 | 自由, 锚定底部, 锚定高度
  ▸ 碰撞          碰撞边距方式与边距值 (默认收起)
```

- **作用对象**：选中碎块即可，同一资产选一块就够；选中多个资产的碎块会一起处理。只选源物体时，若它恰好对应一个资产也能识别。
- **面板值与已应用的值**：面板上的参数只是"下一次应用时用的值"。资产实际使用的值记在资产上。两者不同时面板会提示，点 **读取已应用的设置** 可以把资产的值读回面板。

## 参数

| 参数 | 字段 | 默认 / 范围 | 含义 |
| --- | --- | --- | --- |
| 材料 | `material` | 混凝土 | 选择后把下面五项改成该材料的值，之后仍可手改；手改后面板会提示"选择材料后又手动改过数值"。选"自定义"时不改动数值 |
| 密度 | `density` | 2400 / 1–30000 kg/m³ | 碎块质量 = 体积 × 密度 |
| 摩擦 | `friction` | 0.8 / 0–1 | 碎块之间、碎块与地面滑动时的阻力 |
| 弹性 | `restitution` | 0.05 / 0–1 | 碰撞后保留的速度比例 |
| 线阻尼 | `linear_damping` | 0.1 / 0–1 | 移动速度随时间损失的比例 |
| 角阻尼 | `angular_damping` | 0.2 / 0–1 | 旋转速度随时间损失的比例 |
| 受击前状态 | `activation` | 冻结 | 见下一节 |
| 锚定底部 | `use_anchor_bottom` | 关 | 把最下面的碎块固定住，始终不动 |
| 锚定高度 | `anchor_height` | 0.05 m | 最低点不高于资产最低点加这个高度的碎块被锚定 |
| 碰撞边距 | `margin_mode` | 自动 | 自动：交给 Blender，在凸包内部内嵌 0.04 的边距，太薄的碎块边距为 0；固定：每块都用下面的边距，碰撞形状向外扩大这么多 |
| 边距 | `margin` | 0.001 m | 固定模式使用；应小于碎块间隙的一半 |

材料预设的初值如下。密度取常见工程值；其余是可再调整的起点。

| 材料 | 密度 | 摩擦 | 弹性 | 线阻尼 | 角阻尼 |
| --- | --- | --- | --- | --- | --- |
| 混凝土 | 2400 | 0.8 | 0.05 | 0.1 | 0.2 |
| 砖 | 1900 | 0.8 | 0.05 | 0.1 | 0.2 |
| 石材 | 2700 | 0.7 | 0.1 | 0.1 | 0.2 |
| 玻璃 | 2500 | 0.4 | 0.2 | 0.05 | 0.1 |
| 陶瓷 | 2300 | 0.5 | 0.15 | 0.05 | 0.1 |
| 木材 | 600 | 0.6 | 0.2 | 0.1 | 0.2 |
| 金属 | 7850 | 0.5 | 0.3 | 0.05 | 0.1 |

## 受击前状态

没有粘连时，结构是否稳定完全取决于这一项：

| 状态 | 行为 | 适合 |
| --- | --- | --- |
| 冻结 | 原地不动，也不会被撞动，直到驱动起动它；没被驱动波及的碎块整段不动 | 墙、柱的局部破坏 |
| 休眠 | 从休眠开始，被撞到才醒；相互接触的碎块会成片一起醒来 | 堆放的松散物体，被撞后应该连带散开 |
| 自由 | 第一帧起受重力 | 空中爆炸、坠落 |

**锚定底部**优先于以上三种：被锚定的碎块始终不动。

冻结的碎块不会因为失去支撑而塌落，这是不做粘连的直接结果。

## 应用物理做了什么

1. **前置检查**：
   - 刚体点缓存已烘焙时报错，因为已烘焙的缓存会忽略之后的修改；
   - 资产被复制过、来自旧版本或格式未知时报错。
2. **建立刚体**：场景没有刚体世界时新建。碎块通过链接进刚体世界集合建立刚体数据，原本不在世界里的碎块随后移出。物理设置不改变碎块是否参与模拟。
3. **原点移到体积质心**：Bullet 绕物体原点旋转，原点必须在质心。
   - 世界几何不动；
   - 不封闭或体积接近零的碎块退回顶点平均位置；
   - 网格被多个物体共用时不移动。
4. **静止姿态**：只在第一次应用时记录。之后要改，用 **设为静止姿态**。
5. **逐块写入**：
   - 碰撞形状为凸包；
   - 质量 = 网格体积 × 物体缩放带来的体积比 × 场景单位比例的立方 × 密度，最小 0.001；
   - 网格不封闭时用凸包体积，报告里会写明块数；
   - 再写入摩擦、弹性、阻尼与边距。
6. **记录**：把这次实际使用的全部设置连同修订号记在资产上，模拟据此判断物理是否改过。

中途任何一步失败，本次对碎块的全部改动都会撤回，新建的刚体与刚体世界会被删除。

## 其他操作

| 按钮 | 作用 |
| --- | --- |
| 移除物理 | 删除碎块的刚体数据与资产上的物理记录；原点与静止姿态保留 |
| 设为静止姿态 | 把碎块现在的位置记为静止姿态，物理修订号加一，已有的模拟随之过期；资产已有模拟成果时拒绝执行，要先重置模拟 |
| 读取已应用的设置 | 只选中一个已应用物理的资产时，把它实际使用的设置写回面板 |

## 状态

| 状态 | 条件 |
| --- | --- |
| 未完成 | 还没应用过物理 |
| 已过期 | 碎块数量与应用时不同；有碎块的刚体被删除；资产不可用 |
| 输入未变 | 以上都没有发生 |

## 阶段 API

以下示例在 Blender 内运行，假设扩展安装在 `user_default` 仓库：

```python
import bpy

from bl_ext.user_default.quick_destruction.common import asset
from bl_ext.user_default.quick_destruction.tools.Physics.api import apply_physics

context = bpy.context
roots = asset.resolve(context.selected_objects)
result = apply_physics(context, roots, {"material": "BRICK", "activation": "FROZEN"})
print(result.shards, result.mass, result.open_meshes, result.degenerate)
```

| 函数 | 说明 |
| --- | --- |
| `apply_physics(context, roots, config)` | 返回 `PhysicsResult(shards, mass, open_meshes, degenerate)`。配置只给出 `material` 时，其余物理量取该材料的值；显式给出的字段优先 |
| `remove_physics(context, roots)` | 返回处理的碎块数 |
| `reset_rest(context, roots)` | 返回处理的碎块数 |

`roots` 是资产根集合，可以用 `asset.resolve(objects)` 从任意选中物体得到。
